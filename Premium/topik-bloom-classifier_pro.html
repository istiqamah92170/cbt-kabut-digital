❓ Panduan Pengguna
Alur kerja yang disarankan untuk penggunaan pertama kali:
1️⃣ Isi Database Materi
Buka tab Database Materi.
Pastikan daftar topik sudah sesuai kurikulum madrasah Anda.
Cara cepat: unduh Template Excel, isi, lalu Import Excel.
Atau tambah manual: klik nama Mapel → pilih Kelas → klik + Tambah Materi.
2️⃣ Isi Database Kurikulum (opsional tapi direkomendasikan)
Buka tab Database Kurikulum.
Isi secara berurutan: Regulasi → Kurikulum → CP → TP → ATP → KD/Indikator.
Cara cepat: unduh Template Excel, isi semua sheet, lalu Import Excel.
Database Kurikulum dibutuhkan untuk laporan yang akuntabel secara akademik.
3️⃣ Analisis Soal Excel
Buka tab Analisis Excel.
Upload file soal (.xlsx), pilih Mapel dan Kelas, masukkan API key Gemini.
Klik Mulai Analisis. Setelah selesai, unduh hasil Excel.
File hasil sudah termasuk sheet _Metadata_Analisis untuk audit.
4️⃣ Analisis Soal Tunggal
Buka tab Analisis 1 Soal untuk analisis cepat satu soal.
Pilih tipe soal, masukkan teks, klik Analisis.
📚 Apa itu Database Materi?
Daftar topik/materi per mata pelajaran dan kelas yang digunakan Gemini AI sebagai acuan klasifikasi. Gemini wajib memilih topik dari daftar ini — tidak bisa membuat topik baru.
📊 Import Excel — Format Baris
Kolom wajib: mapel, kelas, materi
Kolom opsional: kurikulum, sumber, instansi

Satu baris = satu topik materi.
Mapel dan kelas baru dibuat otomatis.
Duplikat dilewati secara otomatis.
💾 Export / Backup / Restore
Export JSON — simpan seluruh database ke file .json
Import JSON — muat database dari file .json (menggabungkan, tidak menghapus)
Backup Database — sama dengan Export JSON
Restore Database — ganti seluruh database dengan file .json (hati-hati!)
Reset Default — kembalikan ke database bawaan aplikasi
📖 Urutan Pengisian Manual
Ikuti urutan ini agar relasi antar entitas terbentuk dengan benar:

1. Regulasi — Masukkan dokumen hukum dasar (KMA, Permendikbud, dll)
Contoh: KMA No. 347 Tahun 2022 tentang Kurikulum Merdeka Madrasah

2. Kurikulum — Daftarkan kurikulum yang digunakan
Contoh: Kurikulum Merdeka Madrasah, Kode: MERDEKA-KEMENAG

3. CP (Capaian Pembelajaran) — Satu CP per elemen per fase
Pilih kurikulum, isi mapel, fase (FASE-D untuk MTs), elemen, dan narasi CP

4. TP (Tujuan Pembelajaran) — Turunan CP per kelas/semester
Buka CP yang sesuai → klik tombol TP → tambah TP
Isi kelas, semester, urutan, narasi, dan target Bloom

5. ATP (Alur TP) — Urutan TP dalam satu semester
Isi setelah semua TP sudah dibuat. Salin ID TP dari kartu yang sudah ada

6. KD & Indikator — Khusus untuk Kurikulum 2013 (K13)
Tambahkan KD terlebih dahulu, lalu buka KD → tambah Indikator
📊 Import Excel Kurikulum
Unduh Template Excel dari tombol di toolbar.
Isi sheet sesuai urutan: Regulasi → Kurikulum → CP → TP → ATP → KD → Indikator.

Penting: Nama kurikulum di sheet CP/ATP harus sama persis dengan kolom Nama di sheet Kurikulum agar relasi terbentuk otomatis.

Elemen CP di sheet TP harus sama persis dengan kolom Elemen di sheet CP.
🎯 Kode Fase (Kurikulum Merdeka)
FASE-A = Kelas 1-2 (SD/MI)
FASE-B = Kelas 3-4 (SD/MI)
FASE-C = Kelas 5-6 (SD/MI)
FASE-D = Kelas 7-9 (SMP/MTs) ← paling sering digunakan
FASE-E = Kelas 10 (SMA/MA)
FASE-F = Kelas 11-12 (SMA/MA)
📋 Versioning Entitas
Setiap entitas (CP, TP, KD, dll) memiliki riwayat versi.
ID entitas tidak pernah berubah — hanya versi yang naik saat diedit.
Ini memastikan hasil analisis lama tetap dapat diverifikasi meskipun CP/TP diperbarui.
Klik 📜 X versi pada kartu entitas untuk melihat riwayat perubahan.
📄 Format File Excel Soal
Kolom wajib: tipe, pertanyaan
Kolom opsional: vrl_gambar, opsi_a, opsi_b, opsi_c, opsi_d, kunci

Nilai kolom tipe: pg_teks, pg_gambar, esai, esai_gambar
Urutan kolom boleh berubah — sistem membaca berdasarkan nama header, bukan posisi.
🖼️ Format Gambar / Link Soal
Kolom vrl_gambar diisi URL gambar soal (https://...).
Untuk tipe pg_gambar atau esai_gambar: seluruh soal (dan opsi, jika PG) ada di dalam gambar — kolom pertanyaan boleh dikosongkan, sistem tetap akan memprosesnya.
Gunakan Google Drive (share link publik) atau hosting gambar lainnya yang dapat diakses langsung.
🔍 Analisis 1 Soal
Buka tab Analisis 1 Soal untuk pengecekan cepat tanpa upload file.
Pilih Mata Pelajaran dan Kelas terlebih dahulu, lalu pilih tipe soal (PG Teks/PG Gambar/Esai).
Topik hasil AI dapat dikoreksi manual melalui dropdown jika kurang tepat.
Klik Reset Analisis sebelum menganalisis soal berikutnya.
✨ API Key Gemini
Dapatkan API key gratis di aistudio.google.com.

Jika muncul error kuota, tunggu beberapa menit lalu coba lagi.
Gunakan AI Lokal (Offline) jika tidak ada koneksi internet.
📥 File Hasil Analisis
File .xlsx yang diunduh berisi dua sheet:
Sheet 1 — Data soal + kolom hasil: Topik, Bloom, Kesulitan, Confidence, Kunci_AI, Status_Kunci. Semua baris dapat diedit langsung di tabel sebelum diunduh.
Sheet _Metadata_Analisis — Informasi audit: versi aplikasi, versi prompt, snapshot materi, snapshot kurikulum, versi Knowledge Engine, distribusi Bloom

Tombol Export JSON — simpan Session Record + Soal Records lengkap ke .json
Batch default 10 soal per request untuk menghemat kuota API.

📄 Format JSON — Knowledge Engine Module
{
  "module_id": "TKB-C1-v1.0",
  "module_type": "TKB-C1",
  "version": "1.0",
  "status": "active",
  "description": "TKB rules untuk level C1 (Mengingat)",
  "rules": [
    {
      "id": "C1-001",
      "level": "C1",
      "type": "kko_exact",
      "pattern": ["sebutkan","jelaskan","tuliskan"],
      "weight": 4,
      "reason": "KKO C1 langsung"
    }
  ]
}
Module type prefix harus cocok dengan engine:
TKB-*, BKB-*, DKB-*, PKB-*, RKB-*
📚 Database Materi
Export JSON — tab Database Materi → tombol Export JSON → simpan file ke perangkat.
Import JSON — tab Database Materi → tombol Import JSON → pilih file.
Format lama (v0) otomatis dimigrasi ke v2.0 saat diimport — tidak perlu konversi manual.
Reset Database akan mengembalikan ke data default; riwayat perubahan (changelog) tetap dipertahankan.
🧠 Knowledge Engine
Modul yang sudah diimpor tersimpan otomatis di browser ini (localStorage) — tetap ada setelah refresh halaman.
⚠️ Penting: data ini TIDAK ikut ter-backup jika cache/data browser dibersihkan, atau saat berpindah perangkat/browser lain.
Gunakan tombol Backup Semua Modul di tab Knowledge Engine secara rutin, lalu simpan file hasilnya di Google Drive atau penyimpanan lain.
Gunakan Restore dari Backup untuk memulihkan seluruh modul dari file backup tersebut kapan saja.
⚠️ Catatan Umum Penyimpanan
Seluruh data aplikasi ini (Database Materi, Database Kurikulum, Knowledge Engine, Riwayat Sesi) tersimpan di localStorage browser perangkat ini saja — bukan di server.
Membersihkan cache, data situs, atau menggunakan mode penyamaran akan menghapus semuanya.
Lakukan backup/export rutin ke file, terutama sebelum membersihkan cache browser atau berganti perangkat.
