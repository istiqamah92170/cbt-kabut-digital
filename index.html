CBT Kabut Digital

Bikin CBT Sendiri, Tanpa Ribet Urus Server

Sistem ujian online lengkap — token peserta, anti-kecurangan, koreksi esai, sampai analisis butir soal — jalan di atas Google Sheets milik Anda sendiri. Isi wizard 5 langkah, unduh file setup, selesai.

Cara Kerja
5 langkah, sekitar 5–10 menit
1
Jenis Institusi
Sekolah, kampus, kursus, perusahaan, pemerintah, atau umum — menentukan label kolom otomatis.
2
Identitas
Nama institusi, logo, dan pesan sambutan yang tampil di halaman login peserta.
3
Konfigurasi Ujian
Token, durasi, judul, batas pelanggaran, acak soal, dan tema warna.
4
Bobot Nilai
KKM dan proporsi nilai Pilihan Ganda vs Esai.
5
Preview & Download
Periksa ringkasan, unduh file setup, tempel ke Apps Script — CBT siap dipakai.
Tutorial Bergambar: Setelah File Diunduh
Geser untuk melihat cara memasang file hasil wizard ke Google Sheet Anda

1 Buat Google Sheet Baru

2 Buka Ekstensi → Apps Script

3 Hapus kode yang ada lalu tempel kode GAS hasil download wizard. Tambahkan Library CBT-KD (Script ID di komentar file)

4 Tempel ID Scrip, cari dan temukan CBTKDLib, pilih versi terakhir, klik tambahkan

5 Jangan lupa klik simpan sampai icon disket jadi warna abu-abu lalu Deploy sebagai Web App

12 Pilih Select All, pastikan semua tercentang, klik Continue

13 Salin Url Aplikasi web (Link GAS Soal) untuk di tempel di aplikasi CBT, klik Selesai

14 Kembali ke Spreadsheet, refresh agar perubahan diterapkan. Jika benar akan muncul menu CBT Kabut Digital

15 Jalankan Menu "Setup Sheet Awal"

16 Lanjut ikuti seperti di gambar;

17 Hapus Sheet1 yang kosong. ini adalah contoh soal dengan tipe yang berbeda, tinggal dirubah dengan soal masing-masing, jangan lupa tipe nya disesuaikan

18 Untuk melihat hasilnya atau memulai ujian: Buka aplikasi CBT - Pilih profil (buat jika belum ada) - klik Masuk Ujian

19 Tempel link GAS Soal yang sebelumnya sudah di salin (lihat slade 13), lalu klik Lanjut

20 Masukkan Token Ujian (jika lupa lihat di spredsheet-Konfigurasi) klik Mulai Ujian

Kenapa CBT Kabut Digital
Dibangun untuk institusi yang tidak punya tim IT sendiri

Tanpa Server Sendiri

Jalan di atas Google Sheets & Apps Script yang sudah dimiliki institusi — tidak perlu sewa hosting atau tim IT.

Aman & Terproteksi

Deteksi pelanggaran, kunci sheet otomatis, token reset khusus untuk peserta bermasalah.

Analisis Otomatis

Statistik nilai, tingkat kesukaran soal, deteksi anomali — langsung tersaji per ujian.

Sebelum mulai, kenalan dulu ya
