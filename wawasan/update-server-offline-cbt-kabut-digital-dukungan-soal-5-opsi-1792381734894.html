UPDATE SERVER OFFLINE CBT KABUT DIGITAL: DUKUNGAN SOAL 5 OPSI + PANDUAN PEMASANGAN

19 Oktober 2026

Server offline CBT Kabut Digital memungkinkan ujian CBT berjalan di sekolah yang tidak memiliki sinyal internet sama sekali. Laptop guru menjadi hotspot sekaligus server, dan HP siswa cukup tersambung ke Wi-Fi laptop itu. Versi terbaru kini mendukung soal pilihan ganda 5 opsi (A–E), sama seperti versi online.

APA YANG BARU

- Soal PG teks dengan opsi E tampil lengkap A–E di perangkat siswa.
- Soal PG gambar dengan kunci E otomatis menampilkan tombol E. Untuk soal PG gambar yang punya 5 pilihan tetapi kuncinya bukan E, isi kolom Opsi_E dengan huruf E di sheet Soal.
- Jika opsi E berupa link gambar, gambarnya ikut diunduh saat impor sehingga tetap tampil tanpa internet.
- Jawaban E dinilai otomatis oleh server. Kunci dan pembahasan tidak dikirim ke perangkat siswa.
- Soal 4 opsi tidak berubah sama sekali.

GAMBARAN CARA KERJA (3 TAHAP)

1. Impor soal, di tempat yang ada internet (H-1). Soal dan gambar dari Google Sheets disalin ke laptop.
2. Hari ujian, tanpa internet. Laptop menyalakan hotspot dan server, siswa mengerjakan lewat browser HP.
3. Sinkronisasi, di tempat yang ada internet. Hasil ujian dikirim kembali ke Google Sheets.

ISI PAKET (folder cbt-server)

- JALANKAN-SERVER.bat : tombol start di Windows. Klik dua kali untuk menyalakan server. Jendelanya jangan ditutup selama ujian.
- server.js : program server utama.
- import-soal.js : menyalin soal dari Google Sheets ke laptop.
- sync-ke-sheets.js : mengirim hasil ujian ke Google Sheets.
- arsipkan-ujian.js : menyembunyikan ujian lama dari daftar pilihan siswa. Data tetap tersimpan dan link langsung tetap berfungsi.
- hapus-ujian.js : menghapus permanen satu ujian beserta jawabannya, dengan pengaman berlapis agar tidak terhapus karena salah ketik.
- skema-db.js : berkas pendukung database.
- portal.html : tampilan aplikasi ujian untuk siswa.
- package.json : catatan teknis paket.
- PANDUAN.md : panduan lengkap langkah demi langkah.
- Database cbt.db dibuat otomatis saat impor pertama.

CARA MEMASANG (PENGGUNA BARU)

1. Pasang Node.js versi LTS (minimal 22.5) dari nodejs.org. Cukup sekali per laptop. Cek dengan mengetik node -v di Command Prompt.
2. Ekstrak paket, lalu letakkan folder cbt-server di tempat yang mudah dicari, misalnya Desktop.
3. Ekspor sheet Soal menjadi CSV (File > Download > .csv), simpan di folder cbt-server.
4. Buka Command Prompt di folder cbt-server, lalu jalankan:
node import-soal.js <URL_GAS_SEKOLAH> soal.csv <id-ujian>
Contoh id-ujian: matematika-vii. Tunggu sampai muncul tulisan Berhasil, termasuk proses unduh gambar.
5. Pada hari ujian: nyalakan hotspot laptop, klik JALANKAN-SERVER.bat, lalu bagikan alamat server ke siswa, misalnya http://192.168.137.1:8080/matematika-vii.
6. Setelah ujian, di tempat yang ada internet, jalankan: node sync-ke-sheets.js

Satu server dapat menyimpan beberapa ujian sekaligus. Cukup impor tiap ujian dengan ID yang berbeda.

CARA MEMPERBARUI (PENGGUNA LAMA)

1. Ganti file server.js, import-soal.js, dan skema-db.js dengan versi terbaru.
2. Ganti portal.html dengan Portal terbaru. Portal lama belum bisa menampilkan opsi E.
3. Jangan hapus cbt.db. Database lama diperbarui otomatis, dan soal, jawaban, serta rekap yang sudah ada tetap aman.
4. Untuk ujian yang berisi soal PG teks 5 opsi, impor ulang dengan ID ujian yang sama, setelah ekspor CSV ulang. Pastikan Library CBT sekolah sudah versi terbaru. Jawaban siswa yang sudah masuk tidak terhapus. Soal PG gambar berkunci E tidak perlu diimpor ulang.
5. sync-ke-sheets.js tidak berubah.

CATATAN

- Server offline memerlukan Node.js 22.5 atau lebih baru.
- Ujian lama yang tidak memakai opsi E tidak perlu diimpor ulang.
- Sebelum ujian sungguhan, uji satu soal 5 opsi dari satu HP siswa terlebih dahulu.
