CBT Kabut Digital — Engine Ujian Online

2 Agustus 2026

CBT Kabut Digital (CBT-KD) adalah platform ujian berbasis komputer (Computer Based Test) yang dirancang untuk digunakan oleh berbagai jenis lembaga — sekolah, madrasah, perguruan tinggi, bimbingan belajar, lembaga pelatihan, perusahaan, hingga instansi pemerintah — menggunakan satu codebase yang sama.

Ujian dikelola sepenuhnya melalui Google Spreadsheet sebagai backend. Tidak perlu server khusus, tidak perlu biaya hosting. Cukup salin template, isi soal, bagikan tautan — ujian siap dijalankan.

✅ Fitur Utama

### 🎓 Engine Ujian CBT

✓ Tiga tipe soal: Pilihan Ganda Bergambar (PG Gambar), Pilihan Ganda Teks (PG Teks), dan Esai.
✓ Soal PG Gambar: tampilan horizontal dengan gambar besar dan opsi jawaban di bawah.
✓ Soal PG Teks: tampilan dua kolom — teks/bacaan di kiri, soal di kanan; mendukung gambar ilustrasi.
✓ Soal Esai: *textarea* dengan penghitung karakter, diperiksa guru secara manual via panel koreksi.
✓ Acak urutan soal PG (opsional, dikonfigurasi dari server).
✓ Dukungan teks Arab dengan font khusus (Scheherazade New / Traditional Arabic) dan ukuran font yang dapat disesuaikan.
✓ Zoom gambar soal dengan toolbar +/−/reset dan dukungan scroll dua arah.

### ⏱️ Timer & Kontrol Waktu

✓ Timer hitung mundur dengan tampilan jam:menit:detik.
✓ Peringatan visual dan animasi berkedip saat waktu tersisa 5 menit.
✓ Ujian otomatis selesai saat waktu habis.

### 🔐 Sistem Anti-Kecurangan (Anti-Cheat)

✓ Deteksi perpindahan tab / minimize aplikasi secara real-time (polling 400ms).
✓ Deteksi split-screen dengan pemblokiran overlay layar.
✓ Pemaksaan layar penuh (*fullscreen*) selama ujian berlangsung.
✓ Pemblokiran shortcut berbahaya: F12, Ctrl+U, Ctrl+S, Ctrl+C, PrintScreen.
✓ Sistem pelanggaran bertingkat: peringatan ke-1, ke-2, hingga paksa-selesai.
✓ Pesan pelanggaran kustom yang dapat dikonfigurasi guru (per tingkat).
✓ Token reset khusus untuk peserta yang terkena sanksi (terpisah dari token biasa).
✓ Layar blur otomatis saat ujian tidak aktif (perpindahan tab / kehilangan fokus).
✓ Wake Lock: layar perangkat tidak mati selama ujian berlangsung.

### 📊 Sistem Penilaian

✓ Sistem bobot nilai: PG dan Esai (default 70:30, dapat dikonfigurasi).
✓ Penilaian PG otomatis langsung setelah ujian selesai.
✓ Penilaian Esai manual oleh guru via panel koreksi di Google Spreadsheet.
✓ Nilai akhir Model A: gabungan nilai PG dan Esai berdasarkan bobot.
✓ Predikat otomatis: Sangat Baik, Baik, Cukup, Terus Semangat.
✓ Sinkronisasi nilai dari server setelah pengiriman untuk akurasi maksimal.

### 💾 Draft & Pemulihan Otomatis

✓ Jawaban tersimpan otomatis ke localStorage selama ujian (autosave).
✓ Jika browser ditutup atau koneksi terputus, jawaban dapat dilanjutkan dari draft.
✓ Draft terhapus otomatis setelah ujian selesai dan terkirim.

### 📤 Pengiriman Jawaban

✓ Semua jawaban dikirim dalam satu batch request (efisien, minim koneksi).
✓ Sistem retry otomatis jika koneksi bermasalah.
✓ Rekap akhir dikirim ke Google Spreadsheet secara otomatis.

### 📋 Panel Koreksi Guru (Google Apps Script Sidebar)

✓ Koreksi esai per soal dengan navigasi maju/mundur.
✓ Input poin langsung dari sidebar tanpa buka sheet.
✓ Validasi poin melebihi batas maksimal.
✓ Simpan semua poin sekaligus dalam satu klik.
✓ Pembaruan nilai akhir dan predikat otomatis setelah koreksi esai.
✓ Analisis hasil CBT lengkap: statistik, ketuntasan, distribusi predikat, ranking, analisis butir soal, deteksi anomali (nilai tinggi waktu singkat), catatan pelanggaran.

### 🗂️ Laporan & Analisis

✓ Laporan analisis otomatis di sheet *Analisis_CBT* dengan grafik pie dan bar.
✓ Statistik: jumlah peserta, rata-rata nilai, tertinggi, terendah, tuntas/tidak tuntas.
✓ Ranking peserta dengan medali 🥇🥈🥉.
✓ Analisis butir soal PG: tingkat kesukaran dan distraktor terbanyak.
✓ Deteksi anomali: peserta dengan nilai tinggi dan waktu pengerjaan singkat.
✓ Catatan pelanggaran selama ujian.
✓ Export ke Excel (.xlsx) langsung dari sidebar.
✓ Fitur arsip ke Google Drive (semua sheet termasuk Soal).

### 🏫 Portal Peserta (Multi-Profil)

✓ Manajemen profil peserta dengan UUID permanen per perangkat.
✓ Multi-profil dalam satu perangkat (berguna untuk anggota keluarga atau bergantian).
✓ Riwayat ujian per profil (tersimpan hingga 100 entri).
✓ Detail riwayat: nilai, poin, statistik, status koreksi esai.
✓ Buka kembali pembahasan dari riwayat (jika guru sudah membuka).
✓ Backup dan pemulihan data: ekspor/impor JSON.
✓ Mode gabung (merge) atau ganti semua saat impor backup.
✓ Migrasi skema otomatis antar versi backup.

### 🌐 Branding Institusi dari Server

✓ Nama institusi, logo, warna tema, label field — semua dari konfigurasi server.
✓ Selector institusi otomatis terisi dari nama institusi yang didaftarkan guru.
✓ Dukungan multi-institusi dalam satu ujian (tambah institusi di konfigurasi).
✓ Placeholder dan pesan dapat dikustomisasi per institusi.
✓ Nama singkat institusi tampil di header Portal.
✓ Jika tidak dikonfigurasi, engine menggunakan branding default CBT-KD.

### 🎨 Desain & Pengalaman Pengguna

✓ Antarmuka modern dan responsif (mobile-first).
✓ Tipografi premium: Plus Jakarta Sans + JetBrains Mono.
✓ Navigasi grid nomor soal dengan kode warna status (dijawab, ragu, belum).
✓ Indikator status soal: PG Gambar (ungu), PG Teks (biru), Esai (oranye).
✓ Tampilan hasil ujian dengan pesan motivasi berdasarkan tingkat kejujuran.
✓ Pembahasan soal dengan tampilan dua kolom (PG Teks) dan horizontal (PG Gambar).
✓ Print/cetak pembahasan sebagai PDF langsung dari layar hasil.
✓ Layar loading dengan informasi status pemuatan soal.

### ⚙️ Konfigurasi Terpusat dari Google Spreadsheet

✓ Semua parameter ujian dikonfigurasi dari satu sheet *Konfigurasi*.
✓ Parameter tersedia: token login, durasi, judul, batas pelanggaran, acak soal, buka pembahasan, KKM, bobot PG/Esai, pesan pelanggaran ke-1/2/3, ukuran font Arab, warna tema, identitas institusi, token reset pelanggaran, dan lainnya.
✓ Sheet otomatis terisi dengan konfigurasi default saat setup pertama.
✓ Pengelompokan parameter: 🔐 UJIAN · 📊 PENILAIAN · 💬 PESAN PELANGGARAN · 🎨 TAMPILAN · 🏫 IDENTITAS INSTITUSI · 🔑 TOKEN RESET.
✓ Keterangan tiap parameter tersedia di kolom C.
✓ Cache server 5 menit untuk performa optimal; dapat dihapus manual kapan saja.

### 🔧 Infrastruktur & Teknis

✓ Berbasis Google Apps Script (GAS) — tidak perlu server eksternal.
✓ Kompatibel dengan semua browser modern (Chrome, Edge, Firefox, Safari).
